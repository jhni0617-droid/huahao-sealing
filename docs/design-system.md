# Huahao Sealing Design System

## Direction

Huahao Sealing uses a restrained European industrial B2B style: deep navy, white, high-grade gray, precise grids, factual proof, and clear inquiry paths. The visual tone should feel like a capable OEM manufacturing partner, not a decorative catalog site.

## Color Tokens

- `primary` `#071525`: hero bands, footer, industrial proof panels.
- `primary-light` `#12304c`: dark surface depth.
- `accent` `#1f6feb`: primary CTA, active navigation, data emphasis.
- `background` `#f7f9fc`: technical surfaces and page bands.
- `card` `#ffffff`: cards, forms, catalog items.
- `muted` `#5b6778`: supporting text.
- `border` `#dbe3ee`: card and section borders.

## Typography

- Chinese: system Chinese sans stack.
- English: Inter / Plus Jakarta Sans.
- H1: page identity, bold, tight line height.
- H2: section title, 30-40px range.
- Body: 14-16px, muted color, generous line height.
- Eyebrow labels: uppercase, bold, small, `0.08em` tracking.

## Spacing

- Page sections use `section-padding`.
- Inner width uses `container-wide`.
- Cards use 20-32px internal padding depending on density.
- Catalog/product pages favor dense but readable information blocks.

## Radius And Shadow

- Radius should stay restrained: 6-8px for most elements.
- Avoid large rounded marketing cards.
- Shadows are subtle and only used on hover or layered UI.

## Components

- `PageHero`: dark industrial page header with clear CTA and stats.
- `btn-primary`: blue CTA for inquiry or quote.
- `btn-secondary`: white/outline action for supporting navigation.
- `card-static`: neutral proof and content cards.
- Product cards: technical scan pattern with model, specs, applications, and detail link.
- Forms: structured, compact, engineering-first, with required fields clearly marked.

## Motion

- Hover lift should be minimal.
- Transitions should stay under 300ms.
- Avoid flashy animation, excessive gradients, and decorative effects.

## Conversion Pattern

Every key page should answer:

1. What does Huahao make?
2. Why can the factory be trusted?
3. Which application or product line fits?
4. What information should a buyer send?
5. Where is the quote/contact action?
